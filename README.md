# Танковые бои

Сетевая модель боя на C для Linux, вариант 24.
Сервер хранит поле и применяет планы после ответа обеих сторон. Клиенты A и B рассчитывают планы, наблюдатели получают поле, события и итог боя.

[Отчёт по ДЗ №4 (PDF)](report.pdf)

## Сборка и запуск

Команды выполняются из каталога `IZ1`

```bash
cmake -S . -B build
cmake --build build
```

Запустите сервер, после сообщения «Сервер готов» запустите клиентов в отдельных терминалах

```bash
./build/tanks-server 127.0.0.1 5024 --config data/demo.txt --delay 500
./build/tanks-watch 127.0.0.1 5024
./build/tanks-client 127.0.0.1 5024 A
./build/tanks-client 127.0.0.1 5024 B
```

Для запуска по сети замените `127.0.0.1` во всех командах на IPv4-адрес компьютера с сервером. Справка по параметрам доступна через `--help`

Наблюдателей можно подключать и отключать во время боя. Если отключится A или B, сервер дождётся возвращения клиента с той же буквой и продолжит бой с того же такта

При завершении боя или остановке сервера через Ctrl+C подключённые клиенты получают итог и завершаются. Статистика сохраняется в `battle.log`

## Проверка

Для сетевого теста нужен Python 3

```bash
ctest --test-dir build --output-on-failure
```
